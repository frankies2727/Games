# Project image assets

Drop custom images used by the projects here — for example, a custom
projects-portal icon to replace the built-in Pikachu SVG.

**Only add images you have the rights to** (your own artwork/photos, or
public-domain / royalty-free files — e.g. NASA's image library for space
imagery). Don't add copyrighted stock, watermarked, or screenshot images.

To use one, upload it via GitHub → **Add file → Upload files**, then it gets
referenced from a component by importing it, so Vite handles the `/Games/` base
path and cache-busting automatically.
